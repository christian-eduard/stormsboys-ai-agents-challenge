# Guion Demo 1-2 Minutos

## Objetivo

Ensenar producto, agentes y valor de negocio sin perder ritmo.

## Estructura

### 0:00 - 0:15 Problema

"Digital books are still mostly passive. We turn books into interactive multi-agent worlds."

Mostrar landing/dashboard.

### 0:15 - 0:35 Upload + Analysis

Subir libro demo o mostrar uno ya procesado.

Narrativa:

- Gemini analiza la obra.
- Extrae personajes, lugares y escenas.
- Crea embeddings para recuperacion.

### 0:35 - 1:00 Reader + Character Agent

Abrir lector.

Preguntar a un personaje algo emocional o contextual.

Mostrar:

- Respuesta con personalidad.
- Contexto del libro.
- Memoria/estado.

### 1:00 - 1:25 Scene Orchestrator

Abrir chat de grupo o escena.

Mostrar varios personajes respondiendo de forma coordinada.

Narrativa:

- No es un chatbot unico.
- Hay agentes especializados coordinados.

### 1:25 - 1:40 Voice/Narration

Preparar narracion corta.

Narrativa:

- La experiencia pasa de lectura a interpretacion.
- La demo genera un plan de voz/SSML listo para conectarse a TTS.

### 1:40 - 1:55 Publisher/Admin

Mostrar metricas:

- Personajes mas consultados.
- Engagement.
- Conversaciones.
- Calidad/evaluacion.
- Recomendaciones para publisher/admin.

### 1:55 - 2:00 Arquitectura

Mostrar diagrama:

- Cloud Run.
- Gemini.
- Agent Layer/ADK.
- Cloud SQL + pgvector.
- Observabilidad.

Cierre:

"Stormsboys Libros IA transforms books into observable, evaluable, multi-agent literary experiences on Google Cloud."

## Regla

La demo debe estar grabada con un flujo prevalidado. No improvisar prompts en la grabacion final.
