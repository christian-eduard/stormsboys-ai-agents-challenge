# ADR 0001: Elegir Track 2

## Estado

Superada por `0004-track-3-platform-refactor.md`.

## Contexto

La idea de producto ya esta validada conceptualmente: agentes conversacionales para libros, RAG, memoria, analisis literario y dashboard. El challenge permite optimizar agentes existentes y demostrar mejoras tecnicas, evaluacion y despliegue.

## Decision

La entrega se preparo inicialmente para Track 2: Optimize Existing Agents.
Esta decision queda superada por ADR 0004: Track 3 es ahora la direccion
principal, y Track 2 se conserva como evidencia de calidad.

## Consecuencias

- La narrativa se centra en mejora, evaluacion y observabilidad.
- No partimos de cero funcionalmente, pero si creamos un proyecto nuevo limpio.
- La demo debe mostrar claramente por que el sistema optimizado es mejor.
- La arquitectura debe incluir agentes explicitos y metricas.
