# Alcance

## Incluido En La Entrega

- Flujo web de subida y analisis de libro.
- Extraccion de personajes, lugares, capitulos y escenas.
- Conversacion con personaje individual.
- Conversacion multi-personaje o escena.
- RAG con embeddings.
- Memoria narrativa y estado conversacional.
- Voz o narracion, con nombre tecnico correcto segun proveedor final.
- Dashboard publisher/admin basico.
- Arquitectura desplegable en Cloud Run.
- Evaluacion automatizada de agentes.
- Documentacion de demo y submission.

## Fuera De Alcance Inicial

- Marketplace completo de libros.
- Pagos.
- Produccion movil completa.
- Clonado de voz.
- Editor avanzado para publishers.
- Migracion o copia de otros proyectos.

## Reglas De Producto

- La demo debe ser estable aunque el producto no este completo.
- Cada funcion debe tener una razon en el video.
- No se mostraran credenciales reales.
- No se prometera una tecnologia que no este implementada.

## Producto Minimo Del Challenge

Un libro de demostracion, procesado por Gemini, con:

- 3 a 8 personajes.
- 3 a 6 lugares.
- 3 a 8 capitulos/escenas.
- 1 conversacion individual fuerte.
- 1 conversacion de grupo.
- 1 ejemplo de voz.
- 1 panel con metricas simples.
